# RUNATOMY public assets

One file: the 3D heart shown on the RUNATOMY page at
[otticoded.com/runatomy](https://otticoded.com/runatomy).

`heart.glb` is 3.2 MB, meshopt-compressed, and is loaded in the browser with
three.js. It lives here rather than in the app's own repository because the page
has to fetch it from a public address, and the app's source is private.

Nothing else about RUNATOMY is in this repository.
